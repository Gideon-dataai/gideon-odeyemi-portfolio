CLINICAL ANALYTICS

FHIR API Data Pipeline

Designing a reproducible pathway from standardised healthcare API resources to structured, queryable data.

FHIRSQLPython

The business context

Healthcare systems often represent clinical events through interoperable resources, but analytical questions need reliable structured data and documented transformation rules.

Questions this project explores

  • How can FHIR Patient and Observation resources be mapped into practical analytical tables?
  • How can pagination, missing fields and resource references be handled safely?
  • How can validation checks and repeatable extraction support trustworthy downstream analysis?

Analytical approach

Data extraction

Work with publicly available or synthetic FHIR resources and document the fields required for a repeatable workflow.

Transformation

Build reusable Python processing steps, including data typing, missing-value handling and relational mapping.

SQL analysis

Create queryable tables and simple validation queries to test consistency, joins and completeness.

Documentation

Describe source provenance, schema, limitations and how to reproduce the pipeline.
